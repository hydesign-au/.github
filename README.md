# .github

Shared settings for [hydesign-au](https://github.com/hydesign-au): Safe Settings, Renovate, and the lefthook config its repositories load.

## Renovate

Repositories extend `local>hydesign-au/.github:renovate-config`, the preset in [`renovate-config.json`](renovate-config.json). Rules for a single repository belong in its own `.renovaterc.json5`.
